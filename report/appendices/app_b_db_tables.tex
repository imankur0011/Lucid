\chapter{Complete Database Schema Inventory}
\label{app:db_tables}

This appendix provides the complete schema inventory of all \textbf{63 relational database tables} (62 domain application tables plus 1 Alembic tracking table) implemented in the Lucid PostgreSQL 16 database. All tables are defined via SQLAlchemy 2.0 ORM models and managed using Alembic migrations.
