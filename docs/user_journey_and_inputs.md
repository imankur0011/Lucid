# End-to-End User Journey, Input Schemas, and Investor-Facing Experience
**Application:** Arthava (Intelligent Portfolio Creation & Rebalancing Engine)  
**Document:** `docs/user_journey_and_inputs.md`  
**Standard:** Investor-First Transparency Without Software Implementation Disclosure

---

## 1. Core Architectural Principle: Two-Level Progressive Disclosure

To avoid overwhelming novice retail investors while maintaining institutional-grade rigor, the application adheres to strict progressive disclosure across all screens:

```mermaid
graph TD
    A[Investor View: Level 1 - Simple Explanation] -->|On-Demand Expand| B[Investor View: Level 2 - Financial Detail]
    B -.->|Strictly Restricted Access| C[Authorized Reviewer / Developer Audit Console]

    subgraph Level 1: Simple Explanation
        A1[Plain-Language Goal Fit]
        A2[Target Allocations & Cash]
        A3[Primary Risks & Safety Checks]
        A4[Actionable Next Steps]
    end

    subgraph Level 2: Financial Detail
        B1[Audited Metric Citations & Dates]
        B2[Mathematical Invariant Verification]
        B3[Whole-Share Rounding Accounting]
        B4[Benchmark Comparative Analytics]
    end

    subgraph Internal Developer/Audit (Never in Retail UI)
        C1[LangGraph Agent Orchestration]
        C2[Raw LLM Prompts & Token Traces]
        C3[SQL Schema & Database Tables]
        C4[FastAPI Route Endpoints & Stack Traces]
    end
```

### Level 1: Simple Explanation (Default Retail View)
- **Objective:** Give the investor an immediate, plain-language understanding of what was created, why it fits their goal, what key risks exist, and what action they can take.
- **Language Style:** Fiduciary, calm, transparent, jargon-free.
- **Contents:**
  - Clear summary of the user's recognized goal and capital.
  - Recommended stock allocations with exact rupee amounts and whole shares.
  - Unallocated cash reserve and the practical reason it is retained (share indivisibility).
  - Top 3 plain-English reasons why this combination of companies was selected.
  - Top portfolio risks (e.g., sector tilt, market volatility).

### Level 2: Financial Detail (Investor-Facing Technical View)
- **Objective:** Allow informed investors, family offices, or diligent individuals to inspect the empirical and mathematical evidence behind each recommendation.
- **Language Style:** Rigorous financial terminology with inline glossary tooltips.
- **Contents:**
  - Audited fundamental evidence citations (PE, PB, ROE, Debt/Equity) with observation timestamps and data provider names.
  - Mathematical constraint verification summary (Single-stock concentration $\leq 25\%$, Sector cap $\leq 40\%$, Budget invariant).
  - Quantitative metrics (Portfolio Beta, Annualized Volatility, Expected Sharpe Ratio).
  - Historical benchmark comparisons (3-year CAGR vs. Nifty 50) with explicit historical limitations.

## 2. Input Categorization & Data Minimization

Every piece of data processed by Arthava is classified into one of three strict tiers to uphold the principle of **Data Minimization**:

| Tier | Classification | Definition | Application Policy |
| :--- | :--- | :--- | :--- |
| **Tier 1** | **Required Inputs** | Absolute minimum parameters necessary to calculate a valid mathematical allocation. | Without these, the optimization engine cannot run. User is prompted with clear explanation of necessity. |
| **Tier 2** | **Optional Preferences** | Parameters that refine stock eligibility or asset boundaries to match personal values. | System applies conservative, prudent fiduciary defaults if omitted. |
| **Tier 3** | **Retrieved / Derived Data** | Objective market data, financial metrics, and calculated figures generated by the system. | Never asked of the user. Retrieved from verified market databases and calculated deterministically. |

### Input Schema Table

| Parameter | Tier | Source | Default Value | Why It Is Needed | User Warning If Omitted |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Investment Capital ($B$)** | Required | User Entry | None (Preset options: ₹1L, ₹2.5L, ₹5L) | Defines the exact rupee budget for whole-share purchasing. | "Please specify an investment amount of at least ₹10,000 to construct a viable portfolio." |
| **Time Horizon** | Required | User Entry | Long-term (>5 years) | Determines asset volatility tolerance and rebalancing frequency. | Defaults to Long-term with notice: "Defaulting to >5 years investment horizon." |
| **Risk Tolerance** | Required | Questionnaire / User Entry | Moderate | Bounds portfolio volatility and sets single-stock concentration caps. | Prompts user to complete 5-question risk profile. |
| **Primary Financial Goal** | Required | User Entry | Wealth Creation | Aligns asset selection with capital appreciation vs. capital preservation. | Defaults to Wealth Creation. |
| **Single-Stock Cap ($u_i$)** | Optional | User Slider | 25% (Conservative fiduciary guardrail) | Prevents idiosyncratic company risk from dominating the portfolio. | System applies 25% safety cap automatically. |
| **Sector Cap ($S_k$)** | Optional | User Slider | 40% (Prudent diversification cap) | Protects investor against sector-specific macroeconomic downturns. | System applies 40% safety cap automatically. |
| **Excluded Sectors/Stocks** | Optional | Conversational / Multi-select | None (Empty set $\emptyset$) | Enforces personal or ethical restrictions (e.g., tobacco, defense, fossil fuels). | No exclusions applied; full universe eligible. |
| **Asset Prices ($p_i$)** | Retrieved | NSE/BSE Market Feed | Live / Seeded closing prices | Required to determine whole-share quantities ($q_i = \lfloor w_i B / p_i \rfloor$). | System checks freshness timestamp; warns if data > 24 hours old. |
| **Historical Covariance ($\Sigma$)** | Derived | Market Engine | 3-Year Rolling Return Matrix | Quantifies joint asset volatility for Markowitz SLSQP optimization. | Computed internally; user never enters raw statistics. |

## 3. The 18-Step End-to-End Investor Journey

### Step 1: Discovering Purpose & Product Limitations
- **Investor Goal:** Understand what Arthava does, who it is for, and what it does not do.
- **Screen State:** Landing page with clear fiduciary hero statement: *"Wealth Governed by Principle. Intelligent, verifiable portfolio construction for Indian retail investors."*
- **Visible Disclosures:**
  - Not an automated broker; does not execute real-money trades.
  - Academic & research prototype; SEBI IA educational disclaimer.
- **Inputs:** None.
- **Next Action:** Click "Get Started" or "Generate Portfolio".

### Step 2: Registering & Establishing Account State
- **Investor Goal:** Create a secure profile to save recommendations and revisit portfolio versions.
- **Screen State:** Modal dialog requesting Email, Name, and Password.
- **Visible Safeguards:** Cryptographic JWT session established. Role assigned: `investor`. User data isolated.
- **Validation & Recovery:** Validates email format; requires strong password (min 8 chars). In-line errors for duplicates.
- **Next Action:** Direct transition to Onboarding / Profile setup.

### Step 3: Privacy Notice & Data-Use Transparency
- **Investor Goal:** Feel confident that financial data is safe, private, and not sold to third parties.
- **Screen State:** Privacy card explaining:
  - We do not ask for bank account numbers, PAN, Aadhaar, or brokerage credentials.
  - Answers to risk questions are used solely to compute your personalized asset allocation.
- **Acceptance Criteria:** Investor can review data retention policy and export/delete their profile at any time.

### Step 4: Completing Investor Profile Questions
- **Investor Goal:** Provide background on experience, income stability, and liquidity needs.
- **Screen State:** 3 quick questions: Investment Experience (Novice / Intermediate / Experienced), Income Regularity (Salaried / Business / Variable), Emergency Fund Buffer (Yes / In Progress / None).
- **User-Facing Copy:** *"Understanding your financial safety net helps us ensure you only invest money you won't need in an emergency."*
- **Validation:** Clear radio buttons; 1-click selection.

### Step 5: Defining Goal, Capital, Horizon, and Constraints
- **Investor Goal:** Specify how much to invest, for how long, and for what purpose.
- **Screen State:** Portfolio Generator tab.
- **Inputs:**
  - Capital input field (formatted with rupee symbol ₹ and comma separators, e.g., ₹2,50,000). Preset buttons: ₹1.0L, ₹2.5L, ₹5.0L.
  - Investment Horizon dropdown: Short (<1 yr), Mid (1–5 yrs), Long (>5 yrs).
  - Conversational strategy box (e.g., *"Safe wealth creation for retirement, focus on green energy, avoid tobacco"*).
  - Safety guardrail sliders: Single-stock cap (15%–35%, default 25%), Sector cap (25%–50%, default 40%).
- **Error Behavior:** Entering capital < ₹10,000 displays: *"Minimum recommended portfolio capital is ₹10,000 to enable meaningful whole-share diversification."*

### Step 6: Risk Assessment & Questionnaire Limitations
- **Investor Goal:** Determine authentic risk capacity and behavioral tolerance.
- **Screen State:** Risk Questionnaire tab featuring 5 standardized behavioral scenarios (e.g., *"If your portfolio drops 15% in a market correction, what would you do?"*).
- **Visible Guidance:** Visual risk spectrum (Conservative $\rightarrow$ Moderately Conservative $\rightarrow$ Moderate $\rightarrow$ Moderately Aggressive $\rightarrow$ Aggressive).
- **Important Disclosure:** *"A questionnaire reflects your historical attitude to risk. Sudden life events or severe market crises may require revisiting your allocations."*

### Step 7: Pre-Generation Confirmation
- **Investor Goal:** Review all entered parameters before the engine runs.
- **Screen State:** Summary review card:
  - Capital: ₹2,50,000
  - Horizon: 7 Years (Long-Term)
  - Risk Category: Moderate
  - Guardrails: Max 25% per stock, Max 40% per sector
  - Exclusions: Tobacco, Defense
- **User-Facing Action:** Prominent primary CTA: *"Generate Intelligent Portfolio"*.

### Step 8: Truthful Generation Progress & Status
- **Investor Goal:** Know that the system is actively working, without being exposed to developer logs.
- **Screen State:** Active generation banner with animated progress indicator.
- **Truthful Status Messages (Investor-Facing):**
  1. *"Filtering eligible securities against your ethical exclusions..."*
  2. *"Calculating covariance matrices and risk parameters..."*
  3. *"Optimizing asset weights to minimize volatility (SLSQP)..."*
  4. *"Verifying whole-share feasibility and cash reserves..."*
  5. *"Synthesizing evidence-backed holding rationale..."*
- **Prohibited:** Never show raw agent traces, token costs, Python stack traces, or internal prompt templates.

### Step 9: Reviewing Portfolio Summary, Allocations, and Cash
- **Investor Goal:** See the resulting portfolio at a glance.
- **Screen State:** Holdings & Allocations view.
- **Displayed Financial Outcomes:**
  - **Total Capital:** ₹2,50,000
  - **Allocated Outlay:** ₹2,47,850 (99.14%)
  - **Unallocated Cash Buffer:** ₹2,150 (0.86%)
  - **Contextual Note:** *"Retained in cash due to whole-share pricing constraints. In Indian equities, partial shares cannot be purchased on exchanges."*
  - Interactive sector breakdown donut chart.

### Step 10: Understanding Individual Holdings & Quantities
- **Investor Goal:** Inspect the exact companies, target weights, share counts, and prices.
- **Screen State:** Clear, scannable holdings table with columns:
  - Company & Symbol (e.g., *Reliance Industries Ltd. — RELIANCE*)
  - Sector (e.g., *Energy*)
  - Target Weight (e.g., *18.5%*)
  - Share Quantity (e.g., *6 Shares*)
  - Reference Price (e.g., *₹2,950.00 as of 18 Oct 2026*)
  - Total Rupee Value (e.g., *₹17,700*)

### Step 11: Inspecting Explanations & Supporting Evidence
- **Investor Goal:** Understand *why* each stock is included and what data supports it.
- **Screen State:** Explainability & Citations view.
- **Investor-Facing Content:**
  - **Macro Synthesis:** Plain-English investment thesis for the overall basket.
  - **Per-Holding Rationale Cards:** For each company, outlines its role (Core Compounder, Cyclical Growth, Defensive Dividend).
  - **Audited Evidence Badge:** Shows verified historical metrics: P/E Ratio, Return on Equity (ROE), Debt-to-Equity, and 3-Year Profit Growth.
  - **Source & Date:** Explicit citation (e.g., *"Source: Audited Corporate Filings / NSE Data, observed 30 Sept 2026"*).

### Step 12: Warning on Stale Data or Constraint Conflicts
- **Investor Goal:** Be alerted if market data is old or if personal preferences conflicted.
- **Screen State:** Warning toast or informational callout banner:
  - *Data Freshness Warning:* *"Market data was updated 28 hours ago. Price estimates reflect the most recent available closing prices."*
  - *Constraint Conflict Resolution:* *"You requested a 10% maximum stock cap with a ₹15,000 budget, but top-tier stock prices exceed ₹3,000/share. The engine adjusted allocations to preserve whole-share feasibility."*

### Step 13: Comparing Alternative Scenarios ("What-If")
- **Investor Goal:** See how changing a goal, horizon, or budget changes the portfolio.
- **Screen State:** Counterfactual simulator slider.
- **Example:** Slider shifts risk from *Moderate* to *Conservative*.
- **Instant Preview:** System shows side-by-side reallocation: Equity drops from 80% to 55%; Defensive Large-Caps and Liquid Cash rise; expected volatility decreases by 3.8%.

### Step 14: Saving & Reopening Portfolio Versions
- **Investor Goal:** Keep a permanent record of this recommendation and revisit it later.
- **Screen State:** Saved Recommendation notification with unique reference code (e.g., *Version #3 — Created 18 Oct 2026, 15:30 IST*).
- **User Control:** "Compare with Previous Versions" button opens a multi-version side-by-side matrix.

### Step 15: Portfolio Diagnosis & Simulated Rebalancing
- **Investor Goal:** Evaluate an existing portfolio against target allocations and get whole-share adjustment advice.
- **Screen State:** Diagnosis & Rebalancing tab.
- **Visible Outcomes:**
  - Current vs. Target allocation drift percentages.
  - Actionable adjustment table: *Action (BUY/SELL/HOLD), Quantity, Reference Price, Net Cash Impact*.
  - Post-rebalance cash reserve verification.

### Step 16: Reviewing Historical Benchmark Results
- **Investor Goal:** Gauge how this investment strategy would have fared historically.
- **Screen State:** Backtest Benchmarks tab.
- **Visible Analytics:**
  - Comparative performance curve (Strategy vs. Nifty 50 vs. Equal-Weight Index over 3 years).
  - Tabulated metrics: Annualized Return (CAGR), Volatility, Sharpe Ratio, Maximum Drawdown.
  - **Mandatory Caveat:** *"Backtested performance is simulated using historical data. It does not account for future market regimes, execution slippage, or capital gains taxes."*

### Step 17: Updating Profile Data & Recommendation Invalidation
- **Investor Goal:** Update risk tolerance or horizon when life circumstances change.
- **Screen State:** Profile settings modal.
- **User-Facing Behavior:** When profile risk score changes from Conservative to Aggressive, system prompts: *"Your profile has changed. Would you like to generate a new portfolio version to reflect your updated risk tolerance? Previous versions will remain safely archived."*

### Step 18: Accessing Help, Glossary, & Regulatory Disclosures
- **Investor Goal:** Clarify unfamiliar financial terms and understand regulatory standing.
- **Screen State:** Contextual help drawer and footer.
- **Contents:**
  - Plain-English Glossary: *Sharpe Ratio (Return earned per unit of risk), Beta (Sensitivity to market moves), Concentration Cap (Maximum exposure to a single stock)*.
  - SEBI compliance notice: *Educational prototype developed for research. Consult a SEBI-registered Investment Adviser (RIA) before investing real capital.*
